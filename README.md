# Jarvis Lam — Portfolio Website

Personal portfolio website for Hei Lam (Jarvis), showcasing selected software engineering projects across web development, AI systems, cloud infrastructure, mobile applications, cybersecurity, and developer tooling.

## Featured Projects

The portfolio currently highlights projects including:

- **Face Fighter** — Responsive React boxing mini-game with custom face upload/alignment, desktop and mobile controls, progressive randomized visual damage effects, Classic Mode, and a configurable Time Limit endurance mode.
- **HK Bus Live** — Real-time Hong Kong bus ETA web application.
- **MarkItDown — Python 3.14 Edition** — Python 3.14-compatible modification and packaging workflow.
- **PixelVault** — AI-powered media management platform.
- **Lumina** — Distributed LLM split-inference system.
- **SplitMate** — Native iOS expense-splitting application.

## Technology

The portfolio itself is built as a lightweight responsive website using HTML, CSS, and JavaScript, with a custom Apple-inspired visual system, responsive project cards, modal project details, reveal animations, and light/dark appearance support.

## Running Locally

No build step is required for the portfolio. Open `index.html` directly or serve the directory with any static web server.

For example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project Assets

Project screenshots and images are stored alongside the site files and referenced from `script.js`. Project metadata, descriptions, tags, and links are also maintained in `script.js`.
